# 🧀 Sirny Analytics Dashboard

Потужний веб-інтерфейс для візуалізації та глибокого аналізу даних рітейлу, інтегрований з **Poster POS**.

## 📊 Можливості
- **Динаміка продажів:** Моніторинг виручки, кількості чеків та середнього чеку в реальному часі.
- **Сегментація клієнтів:** Автоматичний аналіз лояльності та виявлення клієнтів у зоні ризику.
- **Margin Guard:** Контроль маржинальності товарів та виявлення позицій з низькою прибутковістю.
- **Погодна аналітика:** Кореляція продажів з погодними умовами (через Open-Meteo).
- **Smart Bundling:** ШІ-конструктор дегустаційних сетів на основі залишків на складі.

## 🛠 Технології
- **Streamlit** (Frontend)
- **Pandas** (Data Processing)
- **Plotly** (Interactive Charts)
- **Cloudflare Tunnel** (Secure Remote Access)

## ⚙️ Запуск
1. Встановіть залежності: `pip install -r requirements.txt`.
2. Налаштуйте `config.json` у директорії `data/`.
3. Запустіть дашборд: `streamlit run dashboard.py`.
